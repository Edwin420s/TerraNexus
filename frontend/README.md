# TerraNexus Web Application

Reserved for the React + Vite web client described by TNX-UI-001. Implement by page families and shared design-system components. The 126-page specification is in `../docs/TNX-UI-001_126_Page_UIUX_Specification.md`.

Required foundations before feature screens: OIDC session integration, organisation/farm context, permission-aware routing, TanStack Query, form validation, design tokens, accessible components, API client, error boundary and offline/stale-data indicators.
