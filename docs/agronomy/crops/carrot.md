# Carrot (Daucus carota) Agronomic & Irrigation Profile

- **FAO-56 Crop Coefficients**: Initial Kc = 0.45, Mid-Season Kc = 1.05, Late Season Kc = 0.9
- **Management Allowed Depletion (MAD)**: 0.4
- **Effective Root Zone Depth**: 0.5 - 0.8m
- **Preferred Soil Texture**: Deep stone-free sandy loam
- **Target Soil Matric Potential**: -25 to -40 kPa

## Agronomic Guidance
Uneven watering causes root forking and longitudinal cracking. Continuous moisture produces smooth cylindrical taproots.
