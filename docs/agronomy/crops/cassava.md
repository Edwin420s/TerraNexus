# Cassava (Manihot esculenta) Agronomic & Irrigation Profile

- **FAO-56 Crop Coefficients**: Initial Kc = 0.3, Mid-Season Kc = 1.1, Late Season Kc = 0.5
- **Management Allowed Depletion (MAD)**: 0.6
- **Effective Root Zone Depth**: 0.8 - 1.5m
- **Preferred Soil Texture**: Light sandy loam
- **Target Soil Matric Potential**: -50 to -80 kPa

## Agronomic Guidance
Highly drought tolerant after root establishment. Supplemental irrigation during first 3 months triples tuber bulking yields.
