# Bulb Onion (Allium cepa) Agronomic & Irrigation Profile

- **FAO-56 Crop Coefficients**: Initial Kc = 0.5, Mid-Season Kc = 1.05, Late Season Kc = 0.75
- **Management Allowed Depletion (MAD)**: 0.3
- **Effective Root Zone Depth**: 0.3 - 0.5m
- **Preferred Soil Texture**: Light friable sandy loam
- **Target Soil Matric Potential**: -20 to -30 kPa

## Agronomic Guidance
Shallow rooting demands frequent light irrigations. Irrigation must cease 2 weeks prior to harvest for bulb curing.
