# Avocado Hass (Persea americana) Agronomic & Irrigation Profile

- **FAO-56 Crop Coefficients**: Initial Kc = 0.6, Mid-Season Kc = 0.85, Late Season Kc = 0.75
- **Management Allowed Depletion (MAD)**: 0.3
- **Effective Root Zone Depth**: 0.4 - 0.7m
- **Preferred Soil Texture**: Highly aerated sandy loam
- **Target Soil Matric Potential**: -20 to -35 kPa

## Agronomic Guidance
Shallow root system is vulnerable to both drought and waterlogging. Waterlogging induces Phytophthora cinnamomi root rot.
