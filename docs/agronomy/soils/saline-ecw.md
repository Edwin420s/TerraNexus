# Irrigation Water Salinity Thresholds (ECw)

- **Field Capacity (FC)**: 0.7% volumetric
- **Permanent Wilting Point (PWP)**: 3.0% volumetric
- **Available Water Capacity (AWC)**: 0.0% volumetric
- **Infiltration Rate**: 0.0 mm/hr

## Soil Management Notes
ECw < 0.7 dS/m has no salinity restriction; ECw > 3.0 dS/m causes severe osmotic root dehydration.
