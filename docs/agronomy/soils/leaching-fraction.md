# Leaching Fraction Calculation for Salinity Control

- **Field Capacity (FC)**: 0.15% volumetric
- **Permanent Wilting Point (PWP)**: 0.2% volumetric
- **Available Water Capacity (AWC)**: 0.0% volumetric
- **Infiltration Rate**: 0.0 mm/hr

## Soil Management Notes
Leaching requirement LR = ECw / (5*ECe - ECw) ensures root zone salts are flushed below active root depth.
