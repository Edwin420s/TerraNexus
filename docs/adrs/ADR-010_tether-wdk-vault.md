# ADR-010: Tether WDK Self-Custodial Vault

## Status
Accepted

## Context
Automating farm input replenishment requires programmable stablecoin payments without relying on volatile local currencies.

## Decision
Integrate Tether Wallet Development Kit (WDK) supporting USD₮ on Polygon PoS and Arbitrum L2.

## Consequences
Low-cost micro-transactions, instant supplier settlement, and self-custodial treasury security.
